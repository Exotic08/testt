# Hướng dẫn cho Claudex

Skill của workspace này được lưu trong thư mục `skills/` ở thư mục gốc của server, mỗi skill là `skills/<tên>/SKILL.md`.
Gọi skill trực tiếp trong chat bằng cách gõ `/` rồi chọn tên skill (hoặc gửi tin bắt đầu bằng `/tên-skill`).
File này (`AGENTS.md`) mô tả quy ước riêng cho workspace hiện tại; agent đọc nó trước khi làm việc.
